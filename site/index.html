A protocol for direct LED control

Opalinx is a binary protocol between host software and addressable LED controllers. It carries device information, configuration, pixel data, output control, and optional operation results over a reliable byte stream.

Read the specification

Protocol scope

The core specifies framing, device information, configuration, pixel transfer, coordinated output, and recovery without prescribing a software or firmware architecture.

01

Framing and validation

COBS framing, CRC protection, defined errors, and transaction correlation over reliable byte streams.

02

LED data and output

RGB, RGBW, and RGBCCT pixel data, channel configuration, and coordinated multi-channel Show operations.

03

Extension points

Information records and namespaced vendor messages allow additive extensions to the core protocol.

Client libraries

Client implementations are documented separately from the protocol. They share the same wire semantics and conformance corpus.
